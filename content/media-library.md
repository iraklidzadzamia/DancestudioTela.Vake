# Tela media library

Последнее обновление: 24 августа 2026 года.

Этот файл фиксирует назначение, происхождение и web-подготовку видеоматериалов, переданных для следующих секций сайта. Исходники на Desktop не изменялись. В GitHub сохраняются готовые для сайта версии: MP4/H.264, WebM/VP9 и poster WebP.

## Общий стандарт

- Кадр: вертикальный 9:16, 720×1280.
- Частота: 30 fps.
- Звук: удалён; ролики предназначены для muted autoplay внутри секций.
- MP4: H.264, CRF 23, fast start, `yuv420p`.
- WebM: VP9, CRF 35.
- Poster: вручную выбранный WebP-кадр.
- Общий вес готового пакета: 53.21 MB вместо примерно 385 MB исходников.
- Путь: `public/media/sections/`.

## Реализация главной страницы · 24 августа 2026

- Все шесть секционных роликов размещены на главной в утверждённом порядке.
- Pro-Am и Kids оформлены как самостоятельные editorial-главы; прежние fake media placeholders на главной удалены.
- Оба tango-ролика объединены в одну главу: `tango-on-bars` — основной фильм, `tango-group` — меньший атмосферный эпизод.
- Вертикальное соотношение 9:16 сохранено без принудительного горизонтального crop; рядом с каждым видео есть локализованный EN/KA/RU смысл и подпись.
- Источники WebM/MP4 подключаются только при приближении секции к viewport; одновременно играет не более одного ролика, вне экрана видео ставятся на паузу.
- Для каждого ролика предусмотрено отдельное управление Play/Pause, `prefers-reduced-motion`, Data Saver fallback на poster и пауза при скрытии вкладки.
- `closing-emotional` расположен непосредственно перед финальным CTA и проигрывается без бесконечного loop.
- Социальные и контактные названия остаются неактивными до получения настоящих URL; неподтверждённые адрес, телефон и ссылки не добавлялись.
